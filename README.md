# Insect Catch Game

This repository contains an interactive Insect Catch Game developed using HTML, CSS, and JavaScript. The game is designed to provide an engaging and entertaining experience where players must catch insects that appear randomly on the screen while competing against time and increasing difficulty levels.

The application is built entirely with front-end web technologies. HTML is used to structure the game's interface, CSS enhances the visual appearance through animations and responsive design, and JavaScript powers the core functionality, including insect generation, movement, score tracking, timer management, and user interactions.

The game begins by allowing players to select an insect type before starting the challenge. Once the game starts, insects appear at random positions on the screen, and players must click on them as quickly as possible to earn points. As the score increases, more insects are generated, making the game progressively more challenging and exciting.

This project demonstrates important web development concepts such as DOM manipulation, event handling, animations, timers, randomization, and dynamic content updates. It also provides practical experience in creating interactive browser-based games using vanilla JavaScript.

The Insect Catch Game is an excellent project for learning front-end development and game logic implementation. It showcases how simple web technologies can be combined to create a fun, responsive, and engaging gaming experience directly within a web browser.
